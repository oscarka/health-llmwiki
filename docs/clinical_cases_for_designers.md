# 10个跨模态健康 Wiki 临床案例设计手册

本手册汇编了 **10 个涵盖不同年龄段、不同病种和复杂多模态/多渠道数据渠道**的健康 Wiki 展示案例。所有个人身份信息（人名、电话、医院名称等）均已彻底脱敏并采用 100% 虚构数据。

本手册旨在向专业视觉与交互设计师（UX/UI Designer）展示系统的**数据呈现维度、Markdown 排版规范、医学警告级别、交互脑图层级，以及原文溯源的对话日志格式**，用于辅助页面排版、字体样式、配色规范和比对面板的交互设计。

---

## 🎨 核心排版组件设计规范 (供设计师参考)

在进行界面设计时，设计师需要特别关注并设计以下 4 类核心视觉交互元素：

1.  **✨ 🪄 AI 导读速览卡片 (顶部)**
    *   **排版特征**：位于 Wiki 页面最上方，在 Markdown 中使用 `<!-- SUMMARY_START -->` 与 `<!-- SUMMARY_END -->` 标签包裹。
    *   **设计建议**：建议使用流光毛玻璃卡片背景（如轻微的渐变蓝/紫，带圆角和软阴影），配合精致的闪烁小魔棒图标，用于突显大模型为医生或病患自动提炼的病情大纲。
2.  **🧠 交互式逻辑思维脑图**
    *   **排版特征**：根据 Markdown 文档中的二级标题 `##` (提取为分支) 和列表项 `*` (提取为分支下的具体叶子节点) 动态渲染。
    *   **设计建议**：需要支持点击折叠与展开。点击具体叶节点（如“一级护理”、“口服阿司匹林”），左侧正文会自动平滑滚动定位到该词句，并给予短暂的黄色高亮呼吸灯背景闪烁。
3.  **🚨 医学警示定制卡片**
    *   **危险警告（红线/过敏史）**：使用 `> [!IMPORTANT]`。建议设计为高饱和度红色边框呼吸灯，搭配醒目的警示图标（如 🚨）。
    *   **异常警示（指标/参数异常）**：使用 `> [!WARNING]`。建议使用黄色/橙色高亮卡片背景（如 ⚠️）。
    *   **康复随访（生活/用药医嘱）**：使用 `> [!TIP]`。建议使用柔和蓝色卡片背景（如 💡）。
    *   **一般备注（核心健康备忘）**：使用 `> [!NOTE]`。建议使用浅灰/白边框低调卡片。
4.  **🔗 双向原文溯源徽章**
    *   **排版特征**：正文中以 `[🔗 溯源](log_xxx_x)` 表现，前端会被编译为带有点击效果的小角标（Citation Badge）。
    *   **设计建议**：点击小角标后，右侧应平滑滑出一个抽屉式原文对照面板（TraceabilityPanel），并在该面板的日志列表中，高亮滚动显示对应的 ASR 录音对话、OCR 检验单或穿戴设备预警日志。
